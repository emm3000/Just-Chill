# E04-01 — Host the privacy policy at a public URL

**Epic:** [E04 — release and compliance](../epics/E04-release-and-compliance.md)

## Done when

- [ ] the content of `docs/PRIVACY_POLICY.md` is reachable at a stable public URL
- [ ] that URL is entered in the Play Console listing
- [ ] the hosted copy and the repo copy are the same text, and how they are kept that way is
  stated

## Context

Play requires a reachable privacy-policy URL because the app offers in-app account deletion. The
document exists in the repo and is current; only the hosting is missing.
