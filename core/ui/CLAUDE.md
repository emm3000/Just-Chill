# :core:ui — CLAUDE.md

The Compose vocabulary every feature shares (ADR 015), on top of `:core:presentation`'s Compose-free half (ADR 024 Decision 2): the navigation vocabulary in `navigation/` — `AppRoute`, `CaptureRoute : AppRoute` and `BottomBarRoute : AppRoute` as plain interfaces, `AppNavigator`, `rememberAppNavigator`, `NavHostBindings` and the `PlatformHostActions` interface — the design system — the tokens in `theme/`, the atoms in `atoms/` (`FormSection` among them), the legacy `Emm*` widgets in `components/`, `Numpad.kt` and the `@Preview` device wrappers in `preview/` — and the pieces more than one feature captures a movement with: the icon and colour catalog in `category/`, `TransactionRow` in `transaction/`, and the account, category and date pickers and `AmountInputSheet` in `sheets/`. It depends on `:core:domain` and `:core:presentation` and nothing else — `checkModuleBoundaries` holds that edge — so Koin, SQLDelight, Supabase and Ktor cannot appear here. `:core:ui` names no feature's route: `AppNavigator` holds a back stack and nothing else, the host supplies every concrete route the entries navigate to, and `popToCapture` keys on `CaptureRoute` instead of a named transaction route.

`justchill.android.compose` (`com.android.library` plus the Compose compiler), namespace `com.emm.justchill.core.ui`, `minSdk = 28`, one `src/main` and one `src/test`. Everything it exposes is `api`: `:core:presentation` rides along because `TransactionRow` takes a `TransactionUi` and the pickers take `SelectableCategory`, the atoms publish `Money`, `YearMonth`, `kotlinx.datetime` and `ImageVector`. Compose itself comes from `justchill.android.compose`, so no Compose coordinate is written here.

## Design system

- Which atom and which token, and why: `.claude/rules/ui-components.md`. That file is the style guide; the values live in `theme/EmmColors.kt`, `EmmType.kt`, `EmmSpacing.kt` and `EmmRadii.kt`. `theme/EdgeGiveback.kt`'s `EmmSpacing.edgeGiveback(artwork)` is the one derivation of `(s12 - artwork) / 2`, the padding a 48dp touch target hands back at a screen edge so its smaller glyph still lands on the rows' column; a feature calls it with the artwork it paints (`EmmRowMenuGlyphSize` for `EmmRowMenu`) instead of writing the difference down (#271). `EmmSpacing.hairline` is the 1dp of every border, rule and selected ring, the one value off the 4dp scale, so `Hairline`, a `border` width and a ring all read it instead of writing `1.dp` (#340).
- `JcTopBar` pads its own edges off that giveback: the start is `column - edgeGiveback(s6)`, so `BackBtn`'s 24dp chevron lands on the screen's column, and the end is `column - edgeGiveback(rightArtwork)`, the artwork the caller paints in `right`. `rightArtwork` defaults to `s12`, the full slot an `IconBtn`, a `HeaderAction` or a pill fills with a bordered box; a caller whose artwork is smaller than its touch target passes that size instead, as Reporte does with `TopBarTileSize` for its 44dp share tile. The `s2` gap sits on both sides of the title, so an overflowing one never ends flush against a slot. `column` defaults to `s4` and names the column the body below lays its rows at, so the bar follows its own screen instead of fixing one value for fourteen: Más, Movimientos and Cuentas pass `s6` because their rows sit there, Reporte takes the default (#310).
- The Inter and IBM Plex Mono faces are this module's own resources under `src/main/res/font/`, reached through `com.emm.justchill.core.ui.R`. `EmmType` is the only file that touches `R`.
- `compose_stability.conf` declares `com.emm.justchill.**` stable, so an atom taking a `:core:domain` `Money` still skips recomposition.
- A new or rebuilt dialog is an `EmmDialog`, never a hand-rolled `Dialog` or an `AlertDialog`; account and transaction still carry raw ones and are the queue, not the precedent. A write in flight passes `inFlightDialogProperties(isInFlight)` and `actionsEnabled = false` together, so the scrim, the back press and both actions stop as one.
- `OutlinedCta` takes a `leading` and a `trailing` slot, both defaulted to none; `Loading` replaces `leading` with the spinner and drops `trailing`. `CtaHeight` and `titleM` are fixed for every CTA: a caller that wants a taller button or a bigger label is asking for a second CTA identity, which ADR 017 refuses.
- Every file in `atoms/` that defines a public composable carries a `@Preview` wrapped in `EmmTheme` (#185). The five without one — `AmountTone.kt`, `CtaTone.kt`, `IconBtnTone.kt`, `PillTone.kt` and `FilteredTextCursor.kt` — declare a tone enum or a `TextFieldValue` helper and no composable at all; a new atom file is expected to ship its preview with it.
- `components/` holds the legacy `EmmButton`, `EmmCard`, `EmmTextInput` widgets. They are not the design system and no new screen reaches for them.

## Capture vocabulary

- `category/` holds the icon catalog the domain's semantic ids resolve against — `AppIconCatalog` (`IconsAll.kt`) — and, in `CategoryResolve.kt`, the `resolvedIcon` getters over `:core:presentation`'s `CategoryUi` and `SelectableCategory`, `selectableColorIds` (the six ids the colour picker offers) and `EmmColors.resolvedColor(colorId)`, the one map from a stored colour name to a `cat*` token: the six ids alias onto themselves and the four legacy ones (`yellow`, `teal`, `pink`, `brown`) onto the token nearest them, so real data needs no migration and an unknown id lands on `catGraphite`. The map hangs off `EmmColors` so a composable resolves through `LocalEmmColors.current` and a caller that builds data first takes the token as a parameter. A stored `ImageVector` or `Color` is the bug this package exists to prevent.
- `transaction/` holds `TransactionRow`, which draws `:core:presentation`'s `TransactionUi`.
- `sheets/` holds `AccountPickerSheet`, `CategoryPickerSheet` and `DatePickerSheet`, shared by the transaction and loan forms, plus `MonthPickerSheet`, shared by the Movimientos list and Reporte. Every one shares one contract: a pick calls `onSelect` (`onConfirm` on `DatePickerSheet`) then `onDismiss`, and the caller closes the sheet in `onDismiss` alone. A sheet used by one feature stays in that feature's own module — `NoteSheet` is the example.
- `SelectorChip`, `FrequentComboChip` and the `CategoryDot` they draw are atoms like any other, under `atoms/`.
- `MonthChevron` is the one month-navigation chevron: a 48dp `rFull` target over a 20dp glyph, its icon and its `"Mes anterior"` / `"Mes siguiente"` description carried by `MonthChevronDirection`; `contentDescription` overrides that label where the same target steps a year, as `MonthPickerSheet` does. `MonthSelector` and `MonthPickerSheet` draw it; a second copy is the bug #310 closed.
